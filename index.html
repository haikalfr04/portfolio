Undergraduate Thesis

Development of a Joint Document Level Sentiment-Topic Model Based on Extended Long Short-Term Memory for Sentiment Analysis

Pengembangan Joint Document Level Sentiment-Topic Model Berbasis Extended Long Short-Term Memory untuk Analisis Sentimen

Most sentiment analysis gives a whole review a single label, even though one review often talks about several things with different opinions. My thesis builds a model that learns sentiment and topics at the same time. It uses xLSTM (Extended LSTM), pre-trained as an autoencoder, to represent text; a shared encoder then feeds both a sentiment classifier and a Deep Embedded K-Means topic detector through multi-task learning.

Tested on IMDB and Yelp reviews, every xLSTM configuration outperformed the LSTM baselines on sentiment, with the best reaching 88.75% accuracy on IMDB and 92.01% on Yelp, and it also produced the most coherent topics on IMDB.

  • NLP
  • Deep Learning
  • xLSTM
  • Multi-Task Learning
  • Topic Modeling
